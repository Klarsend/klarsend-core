# Reporting a security issue

If you believe you have found a vulnerability in this code or in the Klarsend service,
email **security@klarsend.com**. Please include enough to reproduce it; a proof of
concept against your own account and storage is welcome, one against anyone else's is
not.

You will get a human reply. We ask for reasonable time to fix before public disclosure
and we will credit you if you want to be credited.

This repository is a read-only mirror of the monorepo where the fix will land; the
mirror is republished with each client release, so a fix appears here when it ships.
